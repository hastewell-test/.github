# Contributing

This is the organization's default guide. A repo with its own `CONTRIBUTING.md` uses that one instead.

1. For anything larger than a small fix, open an issue first with one of the forms (Bug, Feature, Task).
2. Open a pull request against `main` and link its issue.
3. Pull requests are merged with **Squash and merge** or a merge commit. Rebase merging is off because it drops commit signatures.
